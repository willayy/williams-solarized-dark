# Williams Solarized Dark

A customized Solarized Dark theme with enhanced token semantics, muted variables, and specialized regex/f-string syntax rules.

## Features

- **Variables & Parameters**: Soft muted grey (`#adadadb9`) across variables and parameters, with bold readonly variables.
- **Types & Classes**: Amber bold (`#ff9900b9`).
- **Namespaces**: Purple bold (`#8a59d2b9`).
- **Functions & Calls**: Bold emphasis for definitions and calls.
- **Regular Expressions**: Distinct red accent (`#c70000`) across all regex operators, character classes, anchors, and capture groups.
- **Python f-strings & Template Expressions**: Bright cyan (`#36d0c3`).
- **Punctuation & Brackets**: Balanced white contrast (`#ffffffb9`).
- **Comments & TODOs**: Green (`#62c262b9`) with bold notation for keywords like `TODO` and `FIXME`.

## Local Installation

Link this folder into your editor extensions directory:

```bash
ln -s "$(pwd)" ~/.vscode/extensions/williams-solarized-dark
```

Then reload the editor (`Cmd + Shift + P` -> `Developer: Reload Window`) and select **Williams Solarized Dark** (`Cmd + K`, `Cmd + T`).
