# Williams Solarized Dark

A custom variant of the default solarized dark theme.

## Local Installation

### 1. Package into VSIX (VS Code Extension Package)
```bash
npx --yes @vscode/vsce package
```

### 2. Install into Editor

**Antigravity IDE:**
```bash
antigravity-ide --install-extension williams-solarized-dark-0.1.0.vsix
```

**Visual Studio Code:**
```bash
code --install-extension williams-solarized-dark-0.1.0.vsix
```

*(Alternatively, open the Extensions sidebar in your editor, click `...` at the top right, and select **Install from VSIX...**)*
